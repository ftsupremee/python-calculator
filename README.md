# PyQt6 Desktop Calculator

A modern, lightweight desktop calculator built using **Python** and the **PyQt6** framework. It features a clean, responsive grid layout and supports basic arithmetic operations along with handy shortcuts like answer recall and exponentiation.

---

## ✨ Features

* **Standard Arithmetic:** Addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
* **Display Control:** Clear (`AC`) to reset the screen and Delete (`Del`) to remove the last character.
* **Advanced Options:** 
  * `10^x` shortcut for exponential calculations.
  * `Ans` button to quickly recall and use your last calculated result.
* **Modern UI:** Custom styled buttons with hover effects and a sleek layout.

---
